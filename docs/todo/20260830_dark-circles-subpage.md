# 黑眼圈子頁規劃

建立日期：2026-08-30
網站：https://ycaura.com/

## 目的

新增一個可被獨立搜尋與分享的黑眼圈內容頁，沿用現有妊娠紋服務頁的視覺與閱讀結構，但定位為「局部美學與科普」，不直接宣稱醫療治療或保證改善效果。

## 建議網址

`/knowledge/dark-circles`

父頁為「局部美學與科普」，子頁專注回答黑眼圈相關搜尋意圖。頁面需有獨立 canonical、標題、描述、H1、Breadcrumb 與 Sitemap 項目。

## 頁面內容架構

1. 首屏直接回答：黑眼圈可能呈現色澤、陰影或輪廓落差，應先了解狀態再討論適合的方向。
2. 常見外觀差異：色澤、陰影、淚溝／泡泡眼與周圍肌膚對比。
3. 如何描述自己的狀況：部位、顏色、明暗、左右差異與持續時間。
4. 可討論的美學方向與限制，清楚區分一般資訊與醫療診斷。
5. FAQ：黑眼圈怎麼分辨？黑眼圈可以做皮膚覆蓋嗎？需要先評估什麼？什麼情況應先看醫生？
6. 聯絡 CTA：Facebook、LINE、Instagram、電話，並連回父頁與首頁。

## SEO／AEO 設定

- 建議 Title：`黑眼圈成因與外觀評估｜新北雙和・台北肌膚美學｜瑪菲斯`
- H1 使用明確問句，例如「黑眼圈怎麼看？先分辨色澤與陰影」
- 首段自然包含「黑眼圈、新北、台北、雙和、肌膚美學」等詞，不堆疊關鍵字。
- FAQ 使用清楚的問答段落，並加入 FAQPage JSON-LD。
- 頁面內容、`llms.txt`、首頁內部連結與父頁連結保持一致。
