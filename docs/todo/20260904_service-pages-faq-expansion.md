## 1. 執行背景與痛點分析

目前網站的四大核心服務專頁各僅有 2 題 FAQ：
1. `herbal-stretch-care`（草本撫紋）
2. `skin-camouflage`（皮膚覆蓋術）
3. `colour-matching`（科技測色）
4. `beauty-education`（局部美學與科普）

現有 FAQ 篇幅偏短，存在以下優化空間：
1. **未完全覆蓋雙北顧客最關心的決策疑慮**：如費用是否透明、是否涉及醫療雷射、會不會痛、生理期或產後何時適合、維持時間等。
2. **Google SERP 富媒體搜尋結果（Rich Snippets）未充分佔據**：豐富且結構明確的 FAQPage Schema 能在搜尋結果中佔據更大面積，顯著提升點閱率（CTR）。

## 2. 待辦項目清單

為四大服務頁各擴充 2–3 題高頻客疑，並維持嚴格的「非醫療宣稱與客觀邊界」：

- [x] **3.1 草本撫紋頁（`herbal-stretch-care`）FAQ 擴充**（已完成於 2026-09-04）
  - **Q3：草本撫紋與其他方式有什麼不同？**  
    *A*：雙和店的草本撫紋著重於外觀視覺色澤與質地感受的調和，屬於美容美化與外觀照護服務，不宣稱醫療效能，亦不取代醫療診斷或治療。若想了解侵入性處置，請諮詢合格專科醫師。
  - *合規校準*：依據 `99-待確認事項.md` 孕哺限制與線上照片政策未確認之原則，暫緩新增產後時間規則與照片傳送承諾，確保零未授權宣稱。

- [x] **3.2 皮膚覆蓋術頁（`skin-camouflage`）FAQ 擴充**（已完成於 2026-09-04）
  - **Q3：皮膚覆蓋術的評估重點是什麼？**  
    *A*：皮膚覆蓋術著重於根據周圍原生肌膚的色澤層次進行評估，追求在自然社交距離下整體外觀的協調與融合，屬於外觀美化修飾，而非圖案或色彩創作。
  - **Q4：夏天曬黑或膚色改變後，覆蓋部位會有色差嗎？**  
    *A*：個人膚色會隨季節、日曬與生活型態產生自然變化，若周圍肌膚曬黑，與覆蓋部位可能產生相對對比。因此評估時會以個別目前的肌膚狀態進行說明。
  - *合規校準*：移除未確認之「色乳」成分與術後防曬承諾字樣，嚴守外觀修飾定位。

- [x] **3.3 科技測色頁（`colour-matching`）維持核心問答**（已確認於 2026-09-04）
  - 維持現有 2 題核心問答（為什麼需要測色、是否保證完全一致），依據 `02-服務/科技測色.md` 規範，暫不預設未確認之卸妝與多光源流程規定。

- [x] **3.4 局部美學與科普頁（`beauty-education`）FAQ 擴充**（已完成於 2026-09-04）
  - **Q5：若有明顯的眼袋或淚溝，單純做外觀美學修飾看得出差別嗎？**  
    *A*：淚溝與眼袋通常伴隨皮下結構隆起或凹陷，屬於立體光影問題。外觀修飾僅能調和表面色澤深淺，無法消除立體結構；若想改善組織結構問題，建議先尋求專科醫師評估。
