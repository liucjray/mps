## 1. 執行背景與痛點分析

目前網站的四大核心服務專頁各僅有 2 題 FAQ：
1. `herbal-stretch-care`（草本撫紋）
2. `skin-camouflage`（皮膚覆蓋術）
3. `colour-matching`（科技測色）
4. `beauty-education`（局部美學與科普）

現有 FAQ 篇幅偏短，存在以下優化空間：
1. **未完全覆蓋雙北顧客最關心的決策疑慮**：如費用是否透明、是否涉及醫療雷射、會不會痛、生理期或產後何時適合、維持時間等。
2. **Google SERP 富媒體搜尋結果（Rich Snippets）未充分佔據**：豐富且結構明確的 FAQPage Schema 能在搜尋結果中佔據更大面積，顯著提升點閱率（CTR）。

## 2. 待辦項目清單

為四大服務頁各擴充 2–3 題高頻客疑，並維持嚴格的「非醫療宣稱與客觀邊界」：

- [ ] **3.1 草本撫紋頁（`herbal-stretch-care`）FAQ 擴充**
  - **Q3：草本撫紋與醫美雷射或微針有什麼差別？**  
    *A*：醫美雷射、微針等屬於醫療侵入治療，需由合格醫師操作；瑪菲斯雙和店的草本撫紋屬於美容外觀修飾服務，著重於視覺色彩與層次調和，不宣稱改變真皮層生理構造，亦不宣稱醫療療效。
  - **Q4：產後多久可以開始預約諮詢草本撫紋？**  
    *A*：建議待產後傷口完全癒合、身體修復並經婦產科醫師評估無虞後，再進行外觀美化評估。哺乳期若考慮使用任何外用產品，亦應先諮詢醫師並確認成分。
  - **Q5：如何進行初步線上諮詢？**  
    *A*：可先透過官方 LINE 或 Facebook 私訊傳送欲評估部位的清楚照片，由專人協助初步了解紋路或色澤狀況與合適方向；諮詢費用與服務報價依雙和店預約確認為準。

- [ ] **3.2 皮膚覆蓋術頁（`skin-camouflage`）FAQ 擴充**
  - **Q3：皮膚覆蓋術跟一般的傳統刺青或紋繡有一樣嗎？**  
    *A*：雖然同樣運用色乳修飾視覺外觀，但皮膚覆蓋術更強調根據周圍原生肌膚的色階、明度進行細緻比對與色彩調和，追求在自然社交光線下的原生融合感，而非圖案創作。
  - **Q4：夏天曬黑或膚色改變後，覆蓋部位會有色差嗎？**  
    *A*：人體周邊膚色會隨季節、日曬與代謝動態變化，覆蓋部位與原生肌膚在劇烈日曬後可能產生暫時性對比。因此在諮詢時會充分說明個人日常防曬與生活型態的評估重點。

- [ ] **3.3 科技測色頁（`colour-matching`）FAQ 擴充**
  - **Q3：進行科技測色當天需要注意什麼？需要卸妝嗎？**  
    *A*：測試部位請保持清潔且無彩妝、無防曬或潤色產品，讓儀器與專業人員能觀測最真實的原生肌膚底色。
  - **Q4：為什麼不同室內光源下看膚色會有差別？**  
    *A*：不同光源（如黃光、白光或自然日光）具有不同的演色性，會影響肉眼感知。雙和店在比對時會兼顧多種光線條件，以達到社交距離下的自然平衡。

- [ ] **3.4 局部美學與科普頁（`beauty-education`）FAQ 擴充**
  - **Q5：我有嚴重的眼袋或淚溝，單純做外觀美學修飾看得出差別嗎？**  
    *A*：淚溝與眼袋通常伴隨皮下脂肪與深層結構隆起或凹陷，屬於結構型立體陰影。外觀修飾僅能微調表面色澤深淺，無法消除立體結構；若想改善結構問題，建議先尋求專科醫師評估。
