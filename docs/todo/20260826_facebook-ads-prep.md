# Facebook 廣告投放前待辦

建立日期：2026-08-26  
網站：https://ycaura.com/
目的：確認網站、Meta 廣告帳戶與後續轉換流程，讓廣告可以先小額測試，再依數據決定是否放量。

## 目前判斷

目前網站適合作為廣告落地頁，也可以先測試導向 Facebook 私訊的廣告；但尚未適合直接進行大額、以網站轉換為目標的投放。

目前已具備：

- HTTPS 自有網域與 Cloudflare 部署
- 首頁與四個服務專頁
- 服務說明、常見問題與醫療資訊免責說明
- Facebook 私訊、電話、Email、地址等聯絡方式
- 手機版頁面與清楚的主要 CTA
- 已確認並加入正確的 LINE 預約連結
- 已加入並部署 GA4 基礎追蹤，記錄 pageview 與主要 CTA 點擊

目前主要缺口：

- 尚未安裝 Meta Pixel／Dataset
- 尚未定義主要廣告目標與轉換事件
- 已確認 11:00–19:00 為可聯繫時段，純預約制、無現場營業時段、無固定公休日（2026-08-31 確認）
- 尚未確認 Facebook 粉絲專頁的私訊自動回覆、回覆時段與完整預約流程
- 尚未準備正式的廣告素材與審核安全文案

## P0｜投放前必須確認

### 1. 確認商家公開資訊

- [x] 確認營業時間為 11:00–19:00，採預約制
- [ ] 提供並確認公休日或營業星期
- [ ] 確認 Facebook 粉絲專頁名稱、頭像、封面、地址、電話與網站一致
- [ ] 確認 Facebook 粉絲專頁目前可以正常接收私訊
- [ ] 確認實際服務地點、服務範圍與是否需要預約
- [ ] 確認使用者私訊後由誰回覆，以及預計回覆時間

### 2. 決定第一階段廣告目標

選擇一個主要目標，避免同時追求流量、按讚與預約：

- [ ] Messenger／Facebook 私訊：適合先驗證市場反應
- [ ] 網站轉換：需要先完成 Pixel 與事件追蹤
- [ ] 電話詢問：需要追蹤電話按鈕點擊，並人工記錄實際來電
- [ ] Email 詢問：需要追蹤 Email 按鈕點擊與實際有效詢問

建議第一階段以「有效私訊」或「有效詢問」作為主要結果，不以曝光、按讚或單純點擊率作為成功標準。

### 3. 建立轉換追蹤

若廣告導向網站，需補上：

- [x] 加入 GA4 基礎頁面瀏覽與 CTA 點擊追蹤程式
- [x] 在 GitHub Actions Repository Variables 設定 `NEXT_PUBLIC_GA_MEASUREMENT_ID`
- [ ] 建立 Meta Pixel／Dataset
- [ ] 將網站網域加入並完成 Meta Business 驗證
- [x] 設定 GA4 自動頁面瀏覽事件
- [x] 設定 Facebook、LINE、電話與 Email 點擊事件
- [ ] 以 Meta Pixel／Dataset 設定 Facebook 私訊點擊事件
- [ ] 以 Meta Pixel／Dataset 設定電話點擊事件
- [ ] 以 Meta Pixel／Dataset 設定 Email 點擊事件
- [ ] 為廣告網址加入 UTM 參數
- [ ] 以測試工具確認事件實際送出
- [ ] 依實際追蹤方式確認隱私揭露與使用者告知內容

目前程式碼已加入並部署 GA4 pageview 與 CTA 點擊事件；但尚未發現 `fbq` 或 Meta Pixel。GA4 可用來分析網站行為，不能取代 Meta Pixel 對 Facebook 廣告的最佳化與歸因，因此網站轉換廣告仍需補上 Meta Pixel／Dataset。

### 4. 完成廣告內容與落地頁對齊

- [ ] 決定一個主打服務，不要第一支廣告同時介紹四種服務
- [ ] 廣告標題、圖片、CTA 與落地頁首屏使用相同主題
- [ ] 明確寫出服務地區：新北市中和區／雙和地區
- [ ] 明確寫出下一步：私訊了解、電話諮詢或預約評估
- [x] 使用已確認的 LINE 預約連結
- [ ] 不使用醫療診斷、治療、根治或保證效果等表述
- [ ] 不直接暗示使用者具有某種身體、外貌或健康問題
- [ ] 不使用誇張的前後對比或不實成果承諾

可先採用的方向：

> 新北中和｜肌膚紋路美化與膚色評估。先了解狀態，再討論適合的方向。

- [ ] 補上公休日或營業星期

### 6. 準備廣告素材

- [ ] 確認圖片、文字與服務內容不造成醫療效果誤解

### 7. 建立詢問處理流程

- [ ] 設定 Facebook 私訊歡迎訊息

- [ ] 定義如何記錄預約、取消與成交結果

- [ ] 每次改版後重新測試 Pixel、電話、Email 與 Facebook 連結
- [ ] 定期確認地址、營業時間、Facebook 頁面與服務內容一致

## 第一階段建議驗收標準

滿足以下條件後，才進入小額測試：

- [x] 營業時間已確認並公開
- [ ] 公休日或營業星期已確認並公開
- [ ] Facebook 粉絲專頁可正常接收與回覆私訊
- [ ] 廣告主目標與主要 CTA 已確定
- [ ] 若導向網站，至少已完成主要轉換事件追蹤
- [ ] 廣告文案與落地頁通過一次政策與醫療用語檢查
- [ ] 手機版首頁首屏可在短時間內看懂服務、地區與下一步
- [ ] 已準備可持續回覆詢問的實際人力

第一階段只做小額、短期、單一目標測試；等有效詢問與實際預約資料穩定後，再決定是否增加預算。
