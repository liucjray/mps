## 1. 執行背景與現況缺口

目前 `/knowledge/dark-circles` 是網站最早（2026-08-30）上線的知識子頁。經過全站 Topic Cluster（主題叢集）發展後，與後續建立的妊娠紋指南、肥胖紋與生長紋比對、白色疤痕專題相比，黑眼圈頁存在以下明顯缺口：

1. **缺乏結構化表格（核心缺口）**：
   - 目前黑眼圈頁純以純文字段落呈現，缺少結構化表格。
   - 搜尋引擎與 Google AI Overview 極度偏好「分類矩陣」與「處置比對表」，缺乏表格大幅降低了被選為精選摘要（Featured Snippet）的機會。
2. **缺乏臨床常用的居家自我評估法（Pinch Test）**：
   - 國際皮膚科文獻（PubMed / Mayo Clinic）普遍使用「眼下皮膚輕拉測試（Pinch / Stretch Test）」來輔助區分色素沉澱與微血管淤血，極具實用衛教價值。
3. **缺乏處理途徑三方客觀比對表**：
   - 訪客常困惑於「擦眼霜」、「醫美雷射/玻尿酸」與「外觀美學修飾」的差異，需要清晰的客觀定位表建立理性期待。
4. **側邊欄主題導覽與隱私規範未同步**：
   - 側邊欄缺少新發布的「白色疤痕與手術痕跡」專題連結。
   - 諮詢引導卡片仍包含直接要求上傳近照的描述，需對齊非強制上傳、以文字描述為主的隱私原則。

## 3. 詳細升級內容規格

### 3.1 四大類型辨析矩陣（表格）

| 類型名稱 | 主導成因 | 視覺外觀特徵 | 光線與角度反應 | 拉平皮膚測試反應 |
| :--- | :--- | :--- | :--- | :--- |
| **色素型（Pigmented）** | 真皮或表皮黑色素過度沉積、日曬、反覆摩擦搔抓 | 呈現茶褐色、咖啡色或灰黑色，眼下呈片狀色斑 | 改變光源角度，顏色深度無明顯變化 | 輕拉眼下皮膚，深色痕跡依然清晰，顏色甚至隨皮膚變薄更明顯 |
| **血管型（Vascular）** | 眼周皮下組織薄、微血管充血淤積、過敏性鼻炎 | 呈現青藍色、紫紅色或暗粉色，好發於內眼角至眼中下方 | 熬夜或鼻塞時顏色加深，皮膚溫熱時微幅轉淡 | 輕拉眼下皮膚，微血管被推開或牽拉時，紫藍感可能略微轉淡 |
| **結構型（Structural）** | 眼眶骨骼凹陷、淚溝凹溝、眼袋脂肪凸出造成之立體落差 | 呈現陰影暗沉感，常伴隨眼袋浮腫或淚溝凹陷紋理 | 光線由正上方照射時陰影最重；仰頭或面朝光源時陰影明顯淡化 | 輕拉平整眼下凹凸或以手撫平，立體陰影隨之消失 |
| **混合型（Mixed）** | 同時合併兩種以上因素（臨床最常見，如過敏血管型＋眼窩結構凹陷） | 色彩呈紫棕或暗沉，同時具備立體輪廓與表面色差 | 具備多重特徵，單一角度難以完全消除深色感 | 拉平皮膚後部分色澤存在、部分陰影消失 |

### 3.2 居家自我觀察：眼下皮膚「輕拉測試（Pinch Test）」

在自然光下照鏡子，用食指與拇指輕輕捏起或推開眼下皮膚約 1–2 秒：
1. **觀察顏色是否位移或依舊清晰**：
   - 若拉起後深色感跟著皮膚移動且顏色仍深，多偏向**色素型**。
2. **觀察微血管色澤變化**：
   - 若顏色呈現紫藍色，隨拉開充血退去而稍微變淺，多偏向**血管型**。
3. **仰頭與光源角度觀察**：
   - 拿鏡子將臉面朝正上方光源，若原本眼下暗沉明顯消失，說明主要是**立體結構型陰影（眼袋或淚溝）**。

### 3.3 處置途徑三方客觀比對表

| 評估面向 | 市售日常眼霜／眼部保養品 | 皮膚科／整外專科醫療處置 | 雙和店美學外觀修飾 |
| :--- | :--- | :--- | :--- |
| **主要定位** | 角質層表面保濕滋潤、撫平乾燥細紋 | 針對深層結構、血管或色素進行醫療改善 | 針對眼周表面視覺色階進行調和美化 |
| **常見方式** | 保濕霜、咖啡因／維生素C眼霜、外用防曬 | 血管雷射、皮秒雷射、玻尿酸填補、眼袋外科技術 | 膚色比對、表皮色澤平衡視覺修飾 |
| **介入性質** | 一般化粧品日常保養 | 醫療行為（需由合格專科醫師於院所施作） | 非醫療美容美化與外觀照護 |
| **主要限制** | 無法改變深層血管淤血或真皮黑色素與結構凹陷 | 需承擔醫療風險、費用較高、具恢復期或反黑期 | 無法填平立體眼袋或淚溝凹凸，需個別評估適用性 |
| **合理期待** | 維持眼周肌膚水分彈性、預防乾紋 | 由醫師評估組織結構改善或血管病灶減輕 | 在社交距離下降低表面色差帶來的疲累視覺感 |

### 3.4 預約諮詢前自我檢視清單（以文字描述為主、保護隱私）

- **步驟 1：記錄困擾出現時機**（從小就有、過敏換季時變深，或隨年齡增長出現）。
- **步驟 2：記錄光線與角度感受**（正光還是頂光下明顯、仰頭時是否改善）。
- **步驟 3：說明是否有伴隨狀況**（是否有嚴重鼻塞過敏、眼周發癢紅腫、或乾癢脫皮等醫療疑慮）。
- *隱私提示*：若方便可於自然光下提供無濾鏡近照，亦可先單純以文字描述狀況進行初步了解。

### 3.5 常見問題（FAQ）擴充清單

1. **黑眼圈只有睡不飽造成的嗎？**（原有，精修為直接回答多因素生理成因）
2. **黑眼圈和淚溝、眼袋是一樣的嗎？**（原有，補充立體結構與光影成因）
3. **過敏性鼻炎造成的黑眼圈，可以靠擦保養品消除嗎？**（新增：說明鼻黏膜淤血造成眼周血液循環不良之生理機制，眼霜無法解決鼻塞淤血，應遵醫囑控制過敏）
4. **眼下有明顯淚溝或眼袋，外觀美學修飾看得出差別嗎？**（新增：強調色彩修飾無法填平真皮立體結構，若有立體凹凸應先諮詢醫療專業）
5. **黑眼圈可以做皮膚覆蓋術嗎？**（精修：說明眼周皮膚極薄敏感，需由店家依個人色澤狀態與期望個別溝通，不宣稱醫療效能）
6. **眼下只有單側變深或伴隨疼痛，需要看醫生嗎？**（原有，維持非醫療安全界線）
