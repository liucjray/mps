### 2.3 On-Page 與技術 SEO/AEO 佈局機制

1. **Title 與 Meta Description 範本機制**：
   - 採用 Next.js Metadata API，全站全域 Title 樣板設定為 `%s｜新北雙和店｜瑪菲斯皮膚覆蓋專家`，自動保持品牌一致性與唯一性。
   - Description 強調三大要素：「品牌與地區」、「服務核心內容」、「先評估理解的邊界宣告」，並維持在中文 70–120 字元之 SERP 最佳呈現長度。

2. **問句式標題與 Direct Answer（BLUF 機制）**：
   - 各知識頁均採用「使用者在搜尋框輸入的真實問句」作為 H2／H3（例如：`妊娠紋會完全消失嗎？`、`保濕可以預防妊娠紋嗎？`、`體重瘦下來後，肥胖紋會自己消失嗎？`）。
   - 每個標題下方第一段（`<p className="knowledge-lede">`）直接在 1–2 句話內給出正面定論，隨後才補充機制與個體差異。這完全吻合 Google AI Overviews、Perplexity、ChatGPT Search 擷取「精準摘要（Featured Snippet）」的演算法偏好。

3. **語意三元組（Semantic Triples）與內文佈局**：
   - 內文反覆建立實體關係鏈：`[瑪菲斯雙和店] -- [提供] --> [非醫療外觀美化與草本撫紋]`；`[皮膚擴張紋] -- [包含] --> [妊娠紋、肥胖紋、成長紋]`；`[成熟紋路] -- [特徵] --> [白色萎縮/無血管]`。
   - 避免早期 SEO 堆砌關鍵字（Keyword Stuffing）的低階做法，改以完整醫學術語（英文學名、解剖學層次）與生活化語言交織。

4. **主題集群（Topic Cluster）內部鏈結拓撲**：
   - 結構完整：`首頁 ⇄ 知識 Hub (/knowledge) ⇄ 專題文章 (/knowledge/*) ⇄ 對應商業服務頁 (/services/*)`。
   - 橫向關聯：妊娠紋文章與肥胖紋文章互相建立語意雙向鏈結，避免單篇文章孤立（Orphan Page）。

5. **結構化資料與機器可讀介面**：
   - 全站採用 Schema.org `@graph` 語意關聯，串聯 `Organization`, `LocalBusiness`, `WebSite`, `WebPage`, `Service`, `Article`, `BreadcrumbList`, `FAQPage`, `ItemList`。
   - 針對 AI 搜尋引擎特別維護 `public/llms.txt` 與 `public/llms-full.txt`，提供乾淨、 Markdown 格式的完整實體摘要。
   - `robots.txt` 完整擁抱現代 AI 搜尋爬蟲（GPTBot, ClaudeBot, PerplexityBot, Applebot-Extended 等）。

#### B. 獨特業務 + 在地詞（Unique Commercial + Local Intent）

- **排名表現**：**未進入前 2 頁**。
- **競爭態勢**：
  - `中和 妊娠紋`：被醫療機構壟斷。首頁全為雙和醫院整形外科、杰膚美皮膚科診所（南勢角捷運站旁）、聖仁皮膚科等專科診所的飛梭雷射、微針電波療程。
  - `黑眼圈 淚溝`：被大型醫美集團（玻尿酸填充、熊貓針）與美妝 KOL、Dcard 遮瑕討論文盤據。
  - `肥胖紋 成長紋 妊娠紋 差別`：被高權重健康媒體（康健雜誌、Heho、照護線上）以及**「墨菲斯微針電波（Morpheus8）」**醫美儀器介紹文章佔據。
- **關鍵發現**：「瑪菲斯（Mavis）」與熱門醫美抗老儀器「墨菲斯（Morpheus8）」在中文字面與語音上高度相似，搜尋引擎常將包含「瑪菲斯 + 紋路」的查詢關聯到「墨菲斯微針電波」，產生品牌意圖的競爭干擾。

## 4. 差距分析與待優化問題點

經過關鍵字佈局與實測排名的交叉比對，網站存在以下 5 大核心優化缺口：

```
┌─────────────────────────────────────────────────────────────┐
│                     當前 SEO 關鍵缺口                        │
├──────────────────────────────┬──────────────────────────────┤
│ 1. 缺少 Google 商家地標卡片    │ 失去 Local 3-Pack 最大流量入口 │
│ 2. 醫美儀器「墨菲斯」語意干擾  │ 需強化非醫療遮瑕與儀器之區隔   │
│ 3. 知識頁至服務頁轉換存在摩擦  │ 需增加情境式轉換錨點與預約引導 │
│ 4. 缺乏三方客觀比對工具        │ 缺少「外觀修飾 vs 雷射」比對表 │
│ 5. 新站權重與外部背書不足      │ 缺少真實資歷 Person Schema 與外鏈│
└──────────────────────────────┴──────────────────────────────┘
```

### 4.1 缺口一：在地地圖包（Local 3-Pack）缺席（最關鍵流量瓶頸）
- **現狀**：使用者搜尋「中和 妊娠紋」、「中和 美容」時，Google 優先展示 Google 地圖 3-Pack 卡片。
- **問題**：目前店家 Google 商家檔案尚未完成座標與專屬連結綁定（`hasMap`、`geo` 仍為 Blocked 狀態）。即便網頁 SEO 做得再好，也無法吃下地圖包中高達 40%–50% 的直接來電與導航流量。

### 4.2 缺口二：「瑪菲斯」與「墨菲斯 Morpheus8」的語意混淆
- **現狀**：當使用者搜尋「肥胖紋 瑪菲斯」或「妊娠紋 瑪菲斯」時，AI Overview 第一段有時會先介紹「墨菲斯微針電波（Morpheus8）」，第二段才介紹「瑪菲斯皮膚覆蓋專家」。
- **問題**：受眾容易被誤導以為雙和店提供的是侵入性微針電波儀器，或是因名稱混淆而流失至醫美診所。

### 4.3 缺口三：知識文章的商業轉換承接力（CRO）尚有提升空間
- **現狀**：知識專題頁（如妊娠紋、肥胖紋）文字紮實嚴謹，但側邊欄與文末的 CTA 多為一般性的「LINE 預約諮詢」或「雙和店 Facebook 私訊」。
- **問題**：閱讀完衛教文章的訪客，通常還在「我的狀況到底適不適合」的猶豫期，缺乏情境式的問題引導與清晰的「預約前自我檢視清單」。

### 4.4 缺口四：缺乏「解決方案客觀比對表」（Comparison Grid）
- **現狀**：文章中雖有說明「外觀修飾不等於醫療處置」，但多散落於段落文字中。
- **問題**：現代搜尋者與 AI 引擎極度偏好「結構化表格」。缺少「醫美雷射 vs 外觀覆蓋修飾 vs 日常保養乳霜」的橫向比對表（包含：適合族群、作用深度、疼痛感受、恢復期、預期視覺改變、限制）。

### 4.5 缺口五：E-E-A-T 缺乏具名作者與操作師專家實體
- **現狀**：所有頁面之 `author` 均標記為 Organization，未標記具體操作師姓名。
- **問題**：依據 Google 搜尋品質評估指南（Search Quality Rater Guidelines），健康與外觀修飾屬於 YMYL（Your Money or Your Life）敏感領域，缺乏具名專家履歷會限制文章在泛知識大詞上的排名上限。

## 5. 後續優化調整具體方案（Actionable Plan）

依據影響力（Impact）與執行難易度（Effort），劃分為三大執行階段：

### 5.1 Phase 1（P0 優先級）：在地搜尋與實體訊號打通

#### 任務 1.1：解鎖 Google 商家（GBP）並注入結構化資料
- **執行目標**：待店家提供正式 Google Business Profile 後，立即補齊 `app/site.ts` 內的地理資訊。
- **具體動作**：
  1. 加入經緯度座標：`geo: { "@type": "GeoCoordinates", latitude: 24.987..., longitude: 121.514... }`。
  2. 加入官方商家地圖：`hasMap: "https://maps.app.goo.gl/..."`。
  3. 首頁與聯絡區塊同步更新 Google Maps 嵌入或專屬連結。
- **預期效益**：直接啟動 Google Local Map Pack 資格，搶佔「中和 妊娠紋 覆蓋」、「南勢角 美容遮瑕」地圖前三名。

#### 任務 1.2：強化超微在地關鍵字（Hyper-local Signals）
- **執行目標**：在不堆砌關鍵字的前提下，將周邊指標性生活地標融入文字。
- **具體動作**：
  - 在聯絡與交通指引中，補充：「捷運南勢角站 4 號出口步行約 X 分鐘」、「鄰近中和興南夜市商圈、台北富邦銀行樓上」。
  - 在 Description 與 FAQ 中自然帶入「永和、新店、板橋、土城等雙北鄰近區域方便抵達」。

### 5.2 Phase 2（P1 優先級）：AEO 問答強化、客觀比對表與品牌去混淆

#### 任務 2.1：建立「解決方案三方客觀比對表」
- **執行目標**：在 `/services/herbal-stretch-care` 與 `/knowledge/stretch-marks` 增加響應式比對表格。
- **表格內容設計**：

| 評估維度 | 日常保養品（撫紋霜/油） | 醫美雷射 / 微針電波 | 雙和店草本撫紋 / 皮膚覆蓋 |
| :--- | :--- | :--- | :--- |
| **主要定位** | 表面滋潤、舒緩乾癢 | 刺激膠原新生、組織重建 | 視覺色階調和、外觀美化修飾 |
| **作用層次** | 角質層至表皮淺層 | 真皮層及皮下組織 | 針對表皮色澤落差進行調配 |
| **適合狀態** | 孕期日常預防乾燥 | 早期紅紋或嚴重組織鬆弛 | 成熟穩定白紋、局部色差困擾 |
| **是否為醫療** | 否（一般化粧品） | 是（需合格專科醫師操作） | 否（美容外觀美化照護） |
| **恢復期與感受** | 無恢復期、溫和無痛 | 需局部麻醉、術後紅腫修復 | 非侵入性或微感、依個人耐受 |
| **核心限制** | 無法消除既有真皮紋路 | 費用較高、無法保證完全消失 | 不改變凹凸結構、曬黑需注意對比 |

- **預期效益**：
  - 極高機率被 Google AI Overview 與搜尋引擎直接選為精選摘要（Featured Snippet）。
  - 大幅提升受眾信任度，過濾掉不適合的客群，帶來高意向諮詢。

#### 任務 2.2：品牌關鍵字去混淆（化解「墨菲斯」干擾）
- **執行目標**：在 `/knowledge/striae-comparison` 與 `/services/herbal-stretch-care` 的 FAQ 中，加入明確辨析題：
  - **問句**：「瑪菲斯草本撫紋與醫美常聽到的『墨菲斯微針電波』一樣嗎？」
  - **直接解答**：「兩者完全不同。『墨菲斯（Morpheus8）』屬於高能量醫療電波儀器，需由專科醫師在醫療院所施作；『瑪菲斯新北雙和店』則是專注於膚色比對、視覺色階修飾與草本撫紋的美學工作室，屬於非醫療外觀照護。」
- **預期效益**：導正 AI 知識圖譜（Knowledge Graph），避免潛在客戶被導向醫美診所。
