## 核心發現（2026-11-04 更新）：曝光與點擊集中在少數頁面，已出現部分服務詞曝光

GSC Search Analytics 全站彙總（2026-10-06 至 2026-11-02）為 **489 曝光、21 點擊、CTR 4.29%、平均排名 13.6**；前一個完整 28 天（2026-09-08 至 2026-10-05）為 153 曝光、2 點擊、CTR 1.31%、平均排名 43.4。曝光與點擊均增加，但點擊基數仍小，且這只是自然搜尋表現，不代表諮詢或預約轉換。

頁面維度合計 539 次曝光、21 次點擊；其中 `/knowledge/striae-comparison` 為 251／6，首頁為 100／13，`/services/herbal-stretch-care` 為 22／2；黑眼圈頁為 84／0，妊娠紋知識頁為 28／0。頁面列曝光加總可能高於全站彙總 489；頁面是目前可見點擊的主要來源。服務頁曝光仍少，尚不能據此估計穩定需求。

在查詢維度的可見列中，`皮膚覆蓋術` 首次出現 25 次曝光（平均排名 30.2，0 點擊）；`眼窩凹陷黑眼圈 常見問題` 為 38 次曝光（45.7，0 點擊）；`生長紋肥胖紋差別` 為 16 次曝光（6.8，0 點擊），`striae 中文` 為 21 次曝光（10.4，0 點擊）。`草本撫紋`、品牌加地區詞及多數「覆蓋／遮瑕」長尾詞仍沒有可見曝光列。查詢維度只回傳可見查詢，總曝光和點擊低於全站彙總；不要把查詢列加總當全站總量。

**解讀**：先前「商業詞全部沒有曝光」已被 `皮膚覆蓋術` 的 25 次曝光推翻，但該詞平均排名仍約第 30、沒有點擊；不能據此說需求或轉換已建立。現況仍是少數資訊型頁面帶來大部分曝光與點擊，已依使用者指示對比較頁做有限的 metadata 詞序測試；持續追蹤比較型詞和服務詞，至少累積下一個完整 28 天窗口後再評估，不把變更與排名或點擊變化作因果連結。GSC 查詢列曾對 `妊娠紋` 出現 0 至 1 次曝光的單列差異，故此低樣本值不作趨勢判讀。

## 維護規則

1. 每次跑 `/seo-keyword-audit`，Step 2（覆蓋率分析）先讀這份表，不要重新臨場想關鍵字；查到新的高曝光字詞（不在表裡的）才補進對應主題群。
2. 每次查完 GSC，回來更新對應行的「GSC 近 28 天」欄與日期；「核心發現」段落如果結論有變化（例如商業詞開始有曝光），要同步改寫，不要留著舊結論。
3. 優先度標「待確認」的項目（例如板橋妊娠紋）不能直接排進實作，要先確認 `99-待確認/待確認事項.md` 對應項目是否解除。
4. 這份表不取代 `docs/plan/260917_...md`（那份是完整分析報告，保留當歷史基準）也不取代 `docs/seo/keyword-ledger.md`（那份是逐次執行紀錄），三份文件各司其職，互相連結不互相複製內容。
