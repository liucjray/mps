## 核心發現（2026-09-22）：商業意圖詞目前完全沒有真實搜尋量

用 GSC Search Analytics 逐一查了 260917 報告認定「排名極佳」的品牌詞、商業詞：`瑪菲斯 雙和`、`瑪菲斯皮膚覆蓋專家`、`瑪菲斯皮膚覆蓋專家 新北雙和店`、`草本撫紋`、`皮膚覆蓋術`、`皮膚覆蓋`、`科技測色`，以及「妊娠紋覆蓋」「妊娠紋遮瑕」「黑眼圈遮瑕」「黑眼圈覆蓋」「淚溝遮瑕」這類直接對應「覆蓋／遮瑕」服務意圖的詞——**近 28 天全部 0 曝光**，一組都沒有。

對照之下，**真正有真實曝光的 12 組查詢，全部是「先搞懂這是什麼／為什麼」的資訊型措辭**：`妊娠紋`、`妊娠紋原因`、`板橋妊娠紋`、`眼窩凹陷黑眼圈 常見問題`、`妊娠紋肥胖紋差別` 等，沒有一組帶「覆蓋」「遮瑕」字樣。

**解讀**：260917 報告當時的「排名第一」多半來自報告作者自己手動搜尋當下的單次結果，不代表有真實使用者持續在搜這些詞——`草本撫紋`、`皮膚覆蓋術`這類自創／品牌化的技術詞，一般人根本不知道要搜，自然沒有曝光。想抓到「對妊娠紋、黑眼圈覆蓋有興趣的人」，**現實路徑不是硬衝「覆蓋／遮瑕」這種服務詞的排名（本來就沒人在搜），而是先接住「原因／是什麼／差別」這類真實資訊型搜尋量，再靠頁內轉換（CTA、知識頁→服務頁內鏈）把人帶到服務頁**——這也是目前站上知識頁到服務頁的 Topic Cluster 結構本來就在做的事，方向沒錯，只是知識頁本身的標題/H1 對齊還有優化空間（見下方妊娠紋原因那筆）。

下次查核時，這個「商業詞 vs 資訊詞」的落差如果有變化（例如商業詞開始出現曝光），要更新這一段，不要留著舊結論。

## 維護規則

1. 每次跑 `/seo-keyword-audit`，Step 2（覆蓋率分析）先讀這份表，不要重新臨場想關鍵字；查到新的高曝光字詞（不在表裡的）才補進對應主題群。
2. 每次查完 GSC，回來更新對應行的「GSC 近 28 天」欄與日期；「核心發現」段落如果結論有變化（例如商業詞開始有曝光），要同步改寫，不要留著舊結論。
3. 優先度標「待確認」的項目（例如板橋妊娠紋）不能直接排進實作，要先確認 `99-待確認/待確認事項.md` 對應項目是否解除。
4. 這份表不取代 `docs/plan/260917_...md`（那份是完整分析報告，保留當歷史基準）也不取代 `docs/seo/keyword-ledger.md`（那份是逐次執行紀錄），三份文件各司其職，互相連結不互相複製內容。
